## Phase Goal

**As a** group owner, **I want** to set what the bot says in a group when an admin bans, kicks, mutes, unbans or unmutes someone, from that group's settings in the bot's private chat, **so that** the replies sound like my community, while a group that sets nothing sees no change.

After this plan the bot can store one custom message per group, event and destination, and read all of a group's messages in one cached read that every replica sees at once.

## Planner assumptions (flagged)

- Reversibility: the migration is `costly` (append-only; a later migration can drop the table, nothing existing changes). Recorded here; no checkpoint (unattended run).
- `media_type` uses the `db.TEXT`/`db.PHOTO`/... constants the greetings and rules rows use; 0 means no media. `buttons` is `models.ButtonArray`, whose `Value()` writes `[]` for nil, the way the greetings and rules rows store buttons.
- The cache value is one struct per chat (`Messages` with a map), like `deletion.Rules`; msgpack carries a map of structs.
- The upserts follow `timezone.Set` and `deletion.SetRule`: `clause.OnConflict{Columns: chat_id, event, dest; DoUpdates: AssignmentColumns(<the column(s)>, "updated_by", "updated_at")}` on a `Create` of the full struct, so an insert writes zero values for the other columns and a conflict touches only the targeted ones.
- Rows are kept when every part is removed: an empty row (no text, no file, no buttons, silent false) reads as the default, exactly like no row (`Message.HasContent` false and `Silent` false).
