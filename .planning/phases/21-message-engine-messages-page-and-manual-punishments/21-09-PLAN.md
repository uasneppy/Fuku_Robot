## Phase Goal

**As a** group owner, **I want** to set what the bot says in a group when an admin bans, kicks, mutes, unbans or unmutes someone, from that group's settings in the bot's private chat, **so that** the replies sound like my community, while a group that sets nothing sees no change.

After this plan the owner sees exactly what a member would see, before any punishment happens, from each event screen.

## Planner assumptions and decisions (flagged)

- Full preview: the group's language is read with `lang.GetGroupLanguage(ctx, groupID)` (the Rules preview's read); the target and the actor are the presser (`p.query.From`, not anonymous); the values are the sample reason in the group's language and, for a timed event, `settingsMsgSampleDuration` with an end `settingsMsgSampleSpan` from now; the default is `ev.Default(groupTr, eventDefaultInput{Target, Reason, TimeVal})`; the row is the screen's stored state; the reply's `Opts` are nil, so `eventBotRows` adds no bot row (the Unban and Unmute buttons are live callbacks that must not exist in a private chat; a stated difference of the preview, recorded in AGENTS.md); the composed `media.GreetingMessage` is sent with no `ReplyMsgID` and no `ThreadID` to the presser.
- Preview text sends the custom text filled the same way, with no keyboard; Preview media and Preview buttons reuse the editor's `settingsEditPreviewMediaAlone` and `settingsEditPreviewButtonsAlone` (the stored buttons only).
- The header line is in the presser's language (`settingsEditPreviewSend` sends it with `p.tr`); the content is in the group's, as members see it. A preview ignores Silent: it shows the message the event would post.
- The previews need `settingsRightAdmin` only (the editor's rule): an administrator without `can_change_info` can preview.
- A `{rules}` token makes `FormattingReplacer` read the group's rules row, which creates an empty one for a group without (the join path's own side effect, as for the Welcome preview); the tests of this plan use no `{rules}` so they can assert nothing is written.
