## Phase Goal

**As a** group owner, **I want** to set what the bot says in a group when an admin bans, kicks, mutes, unbans or unmutes someone, from that group's settings in the bot's private chat, **so that** the replies sound like my community, while a group that sets nothing sees no change.

After this plan the owner can silence any of the seven events of a group from its event screen, and the next such command there posts nothing.

<objective>
Add the Silent switch to every event screen (MSG-07, D-14): the page action `hq`, the apply function `applyEventSilent` beside the engine (the switch has no command, so it carries a drift test and an authority test in place of a parity test, D-23), the screen's Silent line, toggle and hint, three strings in 8 languages and the AGENTS.md rule.

Screen change (the event screen of plan 21-06): after the part lines the body gains `settings_msg_line_silent` (`settingsStateWord`) and, after a blank line, `settings_msg_hint_silent`; the keyboard gains one full-width row before Back and Close, the toggle `settings_btn_msg_silent` with the state icon (`settingsStateIcon`) and the data `a=hq&c=<chat>&k=<code>&v=<target>` (42 bytes at a 14-character chat ID), where the target is the opposite of the stored state, so a double tap writes the same value.

Purpose: one of the three ways the owner changes an event (Silent, the editor's parts, the previews), and the simplest, proving the page's writes, rights and drift first.
Output: the apply file, the page changes, one test file, three strings, AGENTS.md.
</objective>

## Planner assumptions (flagged)

- "One setting, one code path": the switch has no command, so `applyEventSilent` is its one write path and the page calls nothing else; it judges no person's rights (the press pipeline judged `settingsRightChangeInfo`). It writes through `eventMsgWrites.Silent` with `eventmsg.DestGroup` and reads the row back with `eventmsg.GetFresh`; a failed write is `greetingSaveFailed` with the error and a nil `Row`; a write whose read-back failed is `greetingApplied` with a nil `Row` (the caller reloads).
- A press always writes its absolute target (a stale screen's press of the stored value writes the same value again and shows no notice), the editor switches' rule.
- The rights are the press pipeline's: viewing `settingsRightAdmin`, the switch `settingsRightChangeInfo` from the press's own live member record (no extra call); the owner gate's carve-out applies (a non-owner administrator with the Access switch off is refused at step 4b).
