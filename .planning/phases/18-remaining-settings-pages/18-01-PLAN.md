## Phase Goal

**As a** group owner, **I want** warnings, reports, language, the log channel, anonymous-admin mode and locks on menu pages, **so that** I can configure them without commands.

After this plan the warn limit can be raised or lowered from a Warnings page in the menu and is stored exactly as `/setwarnlimit` stores it, through one apply function the command now uses too; the action at the limit is extracted the same way and the page shows it.
