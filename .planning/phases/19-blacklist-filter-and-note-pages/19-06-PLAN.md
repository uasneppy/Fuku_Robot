## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a command's arguments and replied-to message to the shared apply function | administrator input; the refactor must not change what is accepted, stored or replied |
| a row ID to the repository | attacker-controlled once a page sends it |
| a stored note to every member | `#name` and `/get` send notes to anyone in the group |
