## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan every welcome, goodbye and rules change has one code path that both the commands and the menu will call, and the message a member sees is built by one function that a preview can call too, so the menu can never store or show something the commands would not.

<objective>
Extract the apply functions and the two message builders the editor shares with the commands (D-09, D-10, D-11; research S-05, S-07, S-08 "Apply functions"; Pattern 2), and make the commands call them with unchanged replies.

Purpose: AGENTS "One setting, one code path": the menu's switches (plan 11-08), Remove (plan 11-09), the typed reply (plans 11-11, 11-13) and the previews (plan 11-12) call these functions and never write or build a greeting themselves.
Output: `greetings.go`, `rules.go` and two new test files.
</objective>
