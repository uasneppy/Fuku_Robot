## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the bot can judge a message the owner typed for a part, before anything is saved: it is converted exactly as the commands convert it, and anything Telegram would refuse at a join is refused with the reason.
