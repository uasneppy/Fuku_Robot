## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the owner opens Welcome, Goodbye or Rules from the settings menu, sees which parts are set, and turns the welcome or goodbye and "Delete last" on or off exactly as the commands do.
