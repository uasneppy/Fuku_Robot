<objective>
The Gemini client the image path and the spike tool share: a small REST client over `net/http` (D-10, no new dependency) in a new leaf package `alita/utils/gemini` that imports only the standard library. `Classify` sends one image with code-owned instructions and reads back exactly two things, a spam probability and a category, in the request and response shape the research verified against Google's v1beta discovery document and keyless probes. Every failure is "no verdict", every error is free of the key, and a retry happens at most once and only within 2 seconds.

Task 1 is the request and the strict verdict parse. Task 2 is the error envelope, the retry, `GetModel` for the spike, and the leaf-package test.

NEVER start PostgreSQL by any means (no su, sudo, setpriv, initdb, pg_ctl, docker). This package has no database at all.

## Phase Goal

**As a** group admin, **I want to** have AI flag borderline spam text and images, **so that** subtler raids still trigger a lockdown.

**This slice:** the bot can ask Gemini about one image and get back a number it can trust, or nothing, and never leaks the key doing so.

## Decisions taken here (Claude's discretion, recorded)

- A `Client{Endpoint, APIKey, Model string; HTTP *http.Client; Options Options}` struct rather than package variables, so the module and the spike tool each build their own and tests pass an `httptest` server URL (PATTERNS: keep exported package vars out).
- `Options` exists for the spike's comparisons only; its zero value is the production request: `SchemaField` (`responseJsonSchema` default, or `responseSchema`, `responseFormat`), `ThinkingLevel` (empty = MINIMAL on `gemini-3*` models and omitted otherwise; `off` = omitted), `OmitTemperature` (false = send 0), `MediaResolution` (empty = `MEDIA_RESOLUTION_MEDIUM`), `SafetyThreshold` (empty = no `safetySettings`), `Store` (`*bool`, nil = omitted). COVERAGE.md opts out of safety settings and `store` in production; the spike can still try them.
- Retry: once, on 429 and 5xx, when the wait (the `RetryInfo.retryDelay` of the error body, else the `Retry-After` header, else 500 ms) is at most 2 seconds, the same rule as the TypeSafe client (`aispamJevDecide`).
- `ErrBlocked` wraps `ErrNoVerdict`, so a caller can count blocks apart (research Pitfall 8) while `errors.Is(err, ErrNoVerdict)` stays true for every no-verdict answer.
- `HTTPError.Error()` prints only `gemini: HTTP <status> <status code name> <reason>`; the server message is kept in `Message`, truncated to 300 runes with every occurrence of the key replaced by `[REDACTED]`, for the spike's probe output only.
- The package logs nothing (no logrus): the caller logs, which keeps it a leaf. The model stage is returned on the verdict so the caller can warn once.
- Environment: golangci-lint cannot lint Go 1.26 here, so `go vet -tags testtools` and `gofmt -l` stand in for `make lint`.
