## Phase Goal

**As a** group admin, **I want to** have AI flag borderline spam text and images, **so that** subtler raids still trigger a lockdown.

**This slice:** the owner can measure, with their own key and their own spam samples, whether Gemini's verdicts are good enough and what they cost, before trusting the image checks.

## Decisions taken here (Claude's discretion, recorded)

- Layout copies `scripts/check_test_results/` (a stdlib `package main` with pure functions beside `main`): `main.go` (flags, modes, I/O), `report.go` (pure: labels, CSV, summary, sweep, percentiles, cost), `probe.go` (the probe's request variants and the reading of each answer), tests beside them. Imports: the standard library and `github.com/divkix/Alita_Robot/alita/utils/gemini` only.
- `main` is a thin wrapper over `run(args []string, getenv func(string) string, stdout, stderr io.Writer, transport http.RoundTripper) int`, so tests drive every mode with a counting `RoundTripper` that fails the test when called, and never touch the network.
- The key is read only from `GEMINI_API_KEY` (never a flag, so it never lands in shell history) and never printed. `-probe` without the key needs the explicit `-fake-key` switch, which uses a built-in, obviously fake key string; with neither, the tool exits 2 having sent nothing (D-17 "calls nothing without a key").
- Labels: a `spam/` or `ham/` parent folder, else a `spam_` or `ham_` file-name prefix; any other file is skipped and counted. Only `.jpg`, `.jpeg`, `.png` and `.webp` files are read, MIME by sniffing, files over `gemini.MaxImageBytes` skipped.
- Default prices are flags (`-price-in 0.30`, `-price-out 2.50`, dollars per million tokens), printed with "verify at ai.google.dev/gemini-api/docs/pricing", because the research could only cite third-party trackers (assumption A2). Cost = prompt tokens times the input price plus (candidate plus thought tokens) times the output price.
- The probe's tiny images: a 1x1 JPEG and PNG built with `image/jpeg` and `image/png`, and a 1x1 WebP as a byte literal (the standard library has no WebP encoder).
- Environment: golangci-lint cannot lint Go 1.26 here, so `go vet -tags testtools` and `gofmt -l` stand in for `make lint`. `make test` compiles and runs `./...`, so this package and its tests run in CI.
