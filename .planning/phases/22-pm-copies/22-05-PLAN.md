## Phase Goal

**As a** group owner, **I want** the bot to also tell a punished person in private, from settings I set group by group in the bot's private
chat, **so that** they know what happened and why, while the punishment and the group message are never delayed or changed.

After this plan the owner sees the private copy before switching it on, and sees on the hub which events send one.

Purpose: the owner can check what a punished person will read; the hub says which events send a private copy.
Output: page changes, one string, two tests, AGENTS.md.
</objective>

## Planner assumptions and decisions (flagged)

- **The preview's reply.** `settingsMsgPMPreview` builds the reply with Phase 21's `settingsMsgPreviewReply(p, groupTr, ev)` (the presser as the
  member, the sample reason, the sample duration and end for a timed event, the group's language from `lang.GetGroupLanguage`) and composes with
  `composeEventPM(p.b, p.group, groupTr, spec, r, row, eventActor{User: &presser})`, where `row` is the screen's stored state; no `PMNote` (the
  lockdown note is a fact of the moment). Full preview sends that composition with `media.SendGreetingMessage` to `p.query.From.Id`; Preview text
  sends the composed text alone; Preview media and Preview buttons are the editor's own (`settingsEditPreviewMediaAlone`,
  `settingsEditPreviewButtonsAlone`). With no text stored, Full preview shows the default private text, so the owner sees what an untouched copy
  says. The editor's `settingsEditPreviewable` stays as it is (a text Preview only while a text is stored).
- **States.** The suffix is code-side (an icon, no words), so no string is needed; Main's `settings_state_msg_n` keeps its words ("{n} custom"),
  and an event with only its private copy on now counts.
- **Expected-set edits.** `TestSettingsMessagesMainState` (and any count it pins) follows the new count; no other Phase 21 test changes.
- **English draft:** `👁 Preview of the private copy, filled in with your name for the member and the admin, a sample reason and, for a timed event,
  a sample time.`
