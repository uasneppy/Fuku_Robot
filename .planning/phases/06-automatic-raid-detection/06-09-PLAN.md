## Phase Goal

**As a** group admin, **I want to** have raids detected and locked down automatically, **so that** my group is protected when no admin is online.

**This slice:** the old raid mode stops temp-banning, and its commands lead admins to the new tools.

## Decisions taken here (Claude's discretion, recorded)

- antiraid.go keeps the AntiRaid module name and help page. The pointer commands are one `helpers.WrapCommand` descriptor (`antiraidRetiredDesc`: name antiraid, aliases raidtime and raidactiontime, Disableable as /antiraid was, no checks because the reply is static text). `/autoantiraid` is `autoantiraidDesc` with `/autolockdown`'s checks (requireLockdownGroup, requireAutoLockdownAuthority) and its anonymous-admin re-entry; with arguments it runs `autolockdownApply` with `joins` prepended, alone it shows the status. The old command was open to any cached admin; it now needs the same live authority as /autolockdown (D-10).
- The old `antiraid|` buttons get one answer (`lockdown_antiraid_retired`) and nothing else; the handler returns ext.ContinueGroups for an update with no callback query, as the old one did.
- The stale keys are cleared by a startup sweep (CONTEXT discretion): once per process, in a goroutine that starts with `defer error_handling.RecoverFromPanic(...)`, bounded by 30 seconds, `SCAN MATCH alita:antiraid:* COUNT 100` with `UNLINK` in batches. Nothing reads those keys any more, so a late or missed sweep only wastes memory. During a rolling deploy an old replica can still temp-ban until it stops (research Pitfall 14); the next start's sweep clears what it left.
- The unused antiraid_* locale strings are removed from all 7 files once a grep shows no Go code reads them; antiraid_help_msg stays and is rewritten. The `alita/db/antiraid` package and the `antiraid_settings` model stay for the legacy backup module (D-20).
- Environment: golangci-lint cannot lint Go 1.26 here, so `go vet -tags testtools` and `gofmt -l` stand in for `make lint`. No PostgreSQL server is available; never start one.
