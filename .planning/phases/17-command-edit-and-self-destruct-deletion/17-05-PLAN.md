## Phase Goal

**As a** group owner, **I want** members' commands, late edits and, when I choose, every message removed automatically, **so that** the group stays clean and an edited message cannot slip spam in later.

After this plan the second rule works: with "Delete edited messages" on, a member's message edited later than the grace is deleted; admins, approved users and every other exempt sender keep theirs, and a lookup that fails keeps the message.

<objective>
Create the `MemberDeletion` module at handler group -8 with the raw edit handler, the grace rule and the shared tri-state exemption helper the self-destruct watcher will reuse in plan 17-07, and register the handler only together with every exemption; prove the slice through the real dispatcher first (a late edit deleted, an early edit kept, an admin's and an approved member's late edits kept), then every exemption and every failing read, the handler's place in the dispatcher, the Staff Group and the rightless group (D-04, D-05, D-06, D-17, D-24, D-28, D-29, D-30, D-33; research S-02, C-08, C-09, C-10).
Purpose: the first handler of the bot that consumes edits; it must never end an update or act on anyone exempt or on a state it could not read.
Output: one production file, a toolkit file, a test file, AGENTS.md.
</objective>
