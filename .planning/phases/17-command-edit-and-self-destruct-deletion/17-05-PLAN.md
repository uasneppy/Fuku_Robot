## Phase Goal

**As a** group owner, **I want** members' commands, late edits and, when I choose, every message removed automatically, **so that** the group stays clean and an edited message cannot slip spam in later.

After this plan the second rule works: with "Delete edited messages" on, a member's message edited later than the grace is deleted; admins, approved users and every other exempt sender keep theirs.
