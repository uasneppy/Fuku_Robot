## Phase Goal

**As a** group owner, **I want** members' commands, late edits and, when I choose, every message removed automatically, **so that** the group stays clean and an edited message cannot slip spam in later.

After this plan the storage layer accepts the three member rules with their exact per-kind delays, can write many self-destruct entries in one statement keeping the earliest time, can count a chat's queue cheaply and drop a pinned message's row; the PostgreSQL guarantees run in CI. Nothing produces member rows yet.
