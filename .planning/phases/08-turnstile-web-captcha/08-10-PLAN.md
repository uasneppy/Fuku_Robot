## Phase Goal

**As a** group admin, **I want to** verify new members with Turnstile in a Telegram Mini App, **so that** bots stay out with little friction.

**This slice:** once the owner sets four variables and restarts the bot, the Mini App button in a group opens a page the bot serves, and the developer can see how the checks are going.

## Decisions taken here (Claude's discretion, recorded)

- `CaptchaWebConfig` gains `TrustedProxies string` (parsed with `captchaweb.ParseTrustedProxies`; an error fails configuration), `PageStrings map[string]map[string]string` (built by `main` from `i18n.GetManager().StringTable(captchaweb.PageLanguages, captchaweb.PageKeys)`, so modules tests can pass a synthetic table) and `StartNotReady bool` (production sets it). With `PageStrings` set the runtime builds `captchaweb.NewPage` with the site key.
- `CaptchaWebRoutes() map[string]http.Handler` returns the three patterns from `Handler.Routes(page)` when a runtime with a page is installed, else nil; `MarkCaptchaWebReady()` calls `SetReady(true)` and is a no-op without a runtime; `CaptchaWebStartupWarnings(metricsTokenSet bool, trustedProxies string) []string` returns the two warnings (it takes no secret, so it cannot leak one).
- `main.go`: right after `httpServer.RegisterDBMetrics()`, when `config.AppConfig.CaptchaWebConfigured()`: build the strings (fatal on error), `modules.ConfigureCaptchaWeb(b, ...)` with `cache.GetRedisClient()` (nil without Redis: the runtime exists, the mode falls back to math and health says unavailable, D-16), register each route with `httpServer.Handle`, log each warning with `log.Warn`; at the very end of `postInit`, `modules.MarkCaptchaWebReady()`. No new shutdown handler (the HTTP server's own Stop runs first; finish tasks join `StopCaptchaLifecycle`).
- `Server.Handle(pattern string, h http.Handler)` registers on the mux, logs `[HTTPServer] Registered <pattern>` and records the pattern so `Start` lists it among its endpoints.
- Counters (`captchaweb/stats.go`, package-level `atomic.Int64`): Issued (a challenge message was sent, `SendCaptcha`), Passed, Failed, Invalid (invalid and not_for_you answers), Retry (retry answers), Limited (429 and the in-flight 503), Errors (configuration faults, backend errors, unmute failures), Expired (a Turnstile attempt the bot timed out: `expireCaptchaAttempt` claimed an attempt whose answer is reserved, whichever replica and path ran it). Counted once per event; numbers only.
