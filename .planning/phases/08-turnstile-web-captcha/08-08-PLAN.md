## Decisions taken here (Claude's discretion, recorded)

- Redis keys (outside `alita:cache:`): `alita:captcha:rl:ip:<ip>` 60 per 60 s, `alita:captcha:rl:u:<user>` 20 per 60 s, `alita:captcha:rl:t:<token>:<user>` 8 per 60 s; one fixed-window script (`INCR`, `PEXPIRE` of the window on the first increment, returns the count) bounded by RedisTimeout; `Limiter.Allow(ctx, key, limit, window) (allowed bool, retryAfter time.Duration, err error)` (retryAfter from the key's PTTL). A Redis error on a window is 503 retry, never an unlimited pass. No in-process map.
- `alita:captcha:done:<token>`: a string `<user>:<result>[:<action>]`, 10 minutes, written after every decided answer (passed, failed, expired); `Store.Done` returns `Decision{UserID, Result, Action}`. A ConsumeUnknown with a Decision for the same verified user replays it with no side effect; for another user it is not_for_you; with no Decision it stays invalid.
- Order (research Pattern 6): write deadline extended (`http.NewResponseController(w).SetWriteDeadline(now + 20 s)`, error ignored, since a recorder does not support it); method; ready flag; in-flight semaphore (a buffered channel of 64, non-blocking); per-IP window (skipped as the Decisions say); content type via `mime.ParseMediaType`; body cap and strict JSON (`DisallowUnknownFields`, then a second `Decode` must return `io.EOF`); initData; per-user window; signed start_param check; per-token-and-user window; consume; then the plan 08-06 steps.
- Readiness: `Options.StartNotReady` (production wiring sets it, plan 08-10) and `Handler.SetReady(bool)`; a handler built without it is ready at once, so the tests of plans 08-01 and 08-06 keep working unchanged.
- Routes: `RoutePage = "GET /captcha"`, `RouteVerify = "POST /captcha/verify"`, `RouteHealth = "GET /captcha/health"` (Go 1.22 method patterns: OPTIONS and GET on the verify path get 405 from the mux, HEAD on the page works, `/captcha/` is a 404); `Handler.Routes(page http.Handler) map[string]http.Handler` returns the three for plan 08-10's `Server.Handle`.
- `ClientIP(r *http.Request, trusted []netip.Prefix) (addr netip.Addr, bucket bool)`; `ParseTrustedProxies(s string) ([]netip.Prefix, error)` accepts IPs (as a /32 or /128) and CIDRs, comma-separated, spaces allowed.
