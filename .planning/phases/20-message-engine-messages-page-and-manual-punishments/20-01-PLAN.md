## Phase Goal

**As a** group owner, **I want** to set what the bot says in a group when an admin bans, kicks, mutes, unbans or unmutes someone, from that group's settings in the bot's private chat, **so that** the replies sound like my community, while a group that sets nothing sees no change.

This plan is the phase's first commit: it freezes today's replies so every later plan can prove "no change" for a group with nothing stored.

<objective>
Record the characterization golden of every manual punishment success reply (MSG-11, D-17) on the unchanged code and commit it alone, before any send site changes. The roadmap's planning notes make this plan 1; it has no production change.

Purpose: MSG-11 is a rule for every phase. The goldens of `bans.go` and `mute.go` do not exist today; without them no later plan can prove a group with no custom message gets byte-identical replies.
Output: one new test file, committed alone.
</objective>
