## Phase Goal

**As a** group owner, **I want** to set what the bot says in a group when an admin bans, kicks, mutes, unbans or unmutes someone, from that group's settings in the bot's private chat, **so that** the replies sound like my community, while a group that sets nothing sees no change.

After this plan all seven manual punishment events of a group post their stored message, and a group with nothing stored keeps every reply of plan 20-01's goldens.

<objective>
Route the six other manual events through the engine of plan 20-04 (EVT-01, D-16): extract each command's default reply into an `eventDefaultReply` builder that gives today's bytes, call `replyEvent` with the event, the target, the values (`{duration}` and `{until}` for the timed ones) and, for `/unmute` during a lockdown, the note; mark the context of an anonymous admin's proof tap so `{admin}` reads "an admin" after the re-entry (MSG-03, D-12).

Purpose: complete EVT-01 on the send side before the page exists.
Output: the six sites, the anonymous mark, one test file, AGENTS.md.
</objective>

## Planner assumptions and decisions (flagged)

- Event per command: `/tban` → `tban`; `/kick` and `/dkick` → `kick` (both through `kickReply`); `/unban` of a member → `unban`; `/mute` and `/dmute` → `mute` (both through `muteReplyWithButton`); `/tmute` → `tmute`; `/unmute` → `unmute`. The per-group `/ban` takes no duration today (`moderationBan` bans with no end date and its reason is the rest of the text), so `tban` is `/tban` alone; nothing about `/ban`'s argument handling changes (MSG-11).
- Values: `Reason` is `t.reason` (empty for `/unban` and `/unmute`, which take no reason); `Duration` is `t.timeVal` (the text the default shows, `2 hours`) and `Until` is `time.Unix(t.untilDate, 0)` for `/tban` and `/tmute`, zero otherwise.
- The default builders reproduce today's text and options exactly: kick `<bans>_kick_kicked_user` plus `<bans>_kick_kicked_reason`, `formatting.Shtml()`; tban `<bans>_ban_tban` with the mention and `timeVal` plus `<bans>_ban_ban_reason`, `Shtml()`; unban `<bans>_unban_unbanned_user`, `Shtml()`; mute `mutes_mute_message` plus `mutes_reason_suffix` and the Unmute keyboard; tmute `mutes_tmute_message` with `timeVal` plus `mutes_reason_suffix`, `Shtml()`; unmute `mutes_unmute_message`, `Shtml()`. `<bans>` is `strings.ToLower(bansModule.moduleName)`, the prefix the sites compute today. The goldens decide: any byte that differs is a defect of the extraction.
- `/unmute` during a lockdown: the site keeps today's lookup; the default is the builder's text plus `"\n" + note` exactly as today, and `Note` carries the same note so a custom text gets it too (`composeEventMessage`'s `Note` rule of plan 20-04).
- The mark is set only by `verifyAnonymousAdmin`, after the proof tap succeeded, so it cannot be forged by a member; every other re-entered command ignores it.
