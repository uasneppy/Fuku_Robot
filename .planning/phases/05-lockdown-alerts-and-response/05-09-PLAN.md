## Phase Goal

**As a** group admin or staff member, **I want to** get a lockdown alert with one-tap fixes, **so that** we can see a raid and clean it up fast.

**This slice:** staff see which invite link the raid used.

## Decisions taken here (Claude's discretion, recorded)

- The link counts come from the burst: pre-lockdown rows and the joiner rows of users with no pre row, grouped by `invite_link`, most used first, ties by link. Join requests' links count like joins. The query lives in its own file (`links.go`) so this plan runs beside plan 05-08 in wave 7 without touching `burst.go`.
- A link is revocable when it is non-empty and contains neither "..." nor "…" (research F2, D-18: other admins' links reach the bot cut short).
- This plan adds no rule to AGENTS.md (it only shows data already stored); plan 05-12 documents the revoke rules.

## Assumptions recorded

- A7 (research): a bot-created invite link arrives in full in chat_member updates; checked in UAT. If Telegram cuts it too, the link is simply flagged as not revocable.
