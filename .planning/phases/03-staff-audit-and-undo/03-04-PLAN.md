<objective>
The "Recent actions" view of the /staff panel. A button on the panel switches the same message to a paged list of this Staff Group's recorded staff actions: who did what to whom, when, why, and how it went in the groups. It reads the audit record from plan 03-01 with one page query and one tally query, and makes no Telegram call to linked groups.

Task 1 is the list end to end: the panel button, the callback, the repository queries, the pure renderer and the locale strings. Task 2 proves access control, the length cap, the callback budget and the rendering of unfinished records, and records the new callback code in AGENTS.md. Each entry's detail view comes in plan 03-05.

Purpose: ROADMAP Phase 3 success criterion 3 (SETUP-09), D-14 to D-16.
Output: staff_history.go, two repository queries, the panel button, locale keys in 7 locales, tests and the AGENTS.md callback rule.
</objective>

## Phase Goal

**As a** staff member, **I want to** log, list and undo every staff action, **so that** mistakes can be reversed and we stay accountable.

**This slice:** any staff member can see, from /staff, every recent staff action of this Staff Group and how it went.

## Decisions taken here (Claude's discretion, recorded)

- Paging uses an offset cursor (`a=rc&o=<offset>`), not a page number: a page whose text must shrink to fit 3800 UTF-16 units shows fewer lines, and Next starts after the last line shown (research Pattern 8).
- Field caps for one line: target name 16 runes, issuer 16 runes, reason 24 runes (each plus "…" when cut), escaped after cutting; `fitStaffSummaryLines` is the safety net.
- The duration is shown compactly as typed (`2d`, `12h`); permanent and over-limit read with the existing `staff_act_duration_permanent` text.
- "Running" versus "interrupted" for a record with no finished_at is decided at render time from updated_at against staffTargetLockTTL (30 minutes); no reconcile job (research Open Question 3).
- The page query asks for 11 rows to know whether a Next button is needed, so no COUNT query is made.
