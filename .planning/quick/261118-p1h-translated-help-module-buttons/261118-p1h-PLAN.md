# Translated help module buttons (Part 1 of the owner-approved plan of 2026-11-18)

1. One `help_module_name_<module>` key per help module in all 8 locale files, at most 14 code points.
2. The /help keyboard is built per reader language on request; the startup-time Ukrainian `markup` is removed. Callback data keeps the internal name.
3. Buttons are sorted by the translated label (locale collation).
4. A missing key falls back to the internal name; a test fails for any help module without a key.
5. The module help header shows the translated name.
6. `/help <name>` also accepts the translated name of the reader's language.
7. Module help keyboards (Filters, Greetings, Notes, Formatting, Reactions) follow the reader's language; the Reactions buttons use their locale keys.
