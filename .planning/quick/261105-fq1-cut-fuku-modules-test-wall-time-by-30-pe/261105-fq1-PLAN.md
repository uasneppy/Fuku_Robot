# Quick task 261105-fq1: shorten `go test -tags testtools -race ./fuku/modules`

## Goal

`./fuku/modules` is the long pole of `make test` (`-timeout 10m` per package). Get the package at least
30 percent faster with the same tests passing and no assertion weakened, or split it with CI still running
everything.

## Measured baseline (this branch, 4 CPUs, warm build cache, `-race -count=1`)

- Package elapsed 560.7 s, 1144 top-level tests, 3513 with subtests, 0 failed, 0 skipped.
- The settings suites are 89 s of that; there is no single dominant test (top test 17 s).
- Fixture timing under `-race`: `withStaffLocale` 312 ms per call, `withRealLocales` 1327 ms per call;
  miniredis, pacer, fake bot, dispatcher, every `Load*` are 1 to 5 ms. `newLockdownEnv` and
  `newSettingsEnv` (295 and 154 call sites, more at run time through subtests) therefore cost about 310 ms
  each, nearly all of it locale parsing.

## Tasks

1. **Build each test locale manager once.** Add `i18n.NewManagerForTest` and `i18n.InstallManagerForTest`
   (testtools helpers); `withStaffLocale` and `withRealLocales` build their manager behind a `sync.Once`
   and install the shared value per test. Locale maps, indexes and translators are read-only after build.
   Unit test for the new helpers in `fuku/i18n`.
2. **Re-measure and rank what is left** from the `-json` output; fix only avoidable cost, in order of size
   (known first candidate: `TestAISpamJevDecideFailsOpenOnHungResponse`, 10 s, whose handler never reads the
   request body so the server never notices the client leaving).
3. **Parallelism and split only if the numbers still need it.** The package shares one SQLite file and global
   cache/locale state, so `t.Parallel()` is not race-safe for these tests; a split is the fallback.

## Constraints (AGENTS.md)

Real fixtures, no mock libraries, always `-tags testtools`, never skip or delete a test, keep
`scripts/check_test_results` and the coverage gate working, `make test` is the only valid full run.

## Verification

`go test -tags testtools -race -count=1 -json ./fuku/modules` before and after (package elapsed, same
pass count, zero skips), `go test -tags testtools -race ./fuku/i18n`, `go vet -tags testtools`, and the
`make test` pipeline for `./fuku/modules ./fuku/i18n` through `scripts/check_test_results`.
