# Rename the bot to Xenobot-72 and rewrite its text in her voice

Rename the bot to Xenobot-72 and rewrite every user-facing value of `locales/en.yml` and
`locales/uk.yml` in the voice of Xenobot-72 (Mau Makan Apa), English and Ukrainian together,
at the flavour level each kind of message allows. The other six locales get only the rename
and the removal of the original project's credits.

## Tasks

1. Value-only edits, batch by key prefix, both files in the same commit. Keys, placeholders,
   markup, command names and arguments unchanged (checked by a script against the original
   English after every batch).
2. Ukrainian written as original text; feminine forms where a gendered form is unavoidable.
3. Rename in the six other locales; credits to the original developers removed.
4. Hardcoded Go strings: developer `/stats` heading, backup `BotName` (old value still accepted
   on import). The updates-channel button is left for the owner to decide.
5. README and docs; `make generate-docs`.
6. Checks: YAML parse, placeholder script, name search, `make check-translations`,
   `make check-docs`, i18n tests, `make test`, `make lint`.

## Out of scope

Module path, package names, Redis keys, env vars, locale key names, LICENSE, AGENTS.md.
