## Phase Goal

**As a** group owner, **I want to** require a profile photo and, in a channel's comment group, a subscription to that channel, **so that** throwaway accounts and outsiders are screened too, without anyone punished because a lookup failed.

After this plan the channel rule is offered only in a group linked to a channel: a stale screen, a stale card or a forged button cannot set a punishment for a group with no linked channel, and a link that cannot be read refuses instead of guessing.

<objective>
Add the live link check (`settingsMreqChannelGate`) at the two places a punishing channel value would be written or carded, with the named tests for every branch, and extend the table-driven Phase 13 settings tests to the channel rule's non-Off values (D-05, D-06, D-08, D-14; UI-SPEC section 5, section 6, checks 3, 8, 9; research S-09 item 6, Pitfall 10).
Purpose: this completes MREQ-12's "offered only in a group linked to a channel": the Off-only screen draws it, and this gate enforces it against everything the screen cannot control.
Output: the gate, a new test file, extended Phase 13 settings tests, AGENTS.md.
</objective>
