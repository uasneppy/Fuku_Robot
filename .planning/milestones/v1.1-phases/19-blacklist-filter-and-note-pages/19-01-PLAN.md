**As a** group owner, **I want** to browse, delete and add blacklisted words, filters and notes from the bot's private chat, **so that** I can manage long lists without commands.

After this plan every blacklist write (add, remove, action) goes through one apply function that the commands already use, the blacklist can be read and a word deleted by its row ID without touching another chat, and the database accepts every action the command offers.
