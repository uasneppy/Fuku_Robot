## Phase Goal

**As a** group owner, **I want** members' commands, late edits and, when I choose, every message removed automatically, **so that** the group stays clean and an edited message cannot slip spam in later.

After this plan the bot knows, at run time, every command name it registers. Command deletion (plan 17-03) uses it to delete only commands addressed to this bot.

<objective>

Purpose: D-01 says only commands this bot registers are deleted; there was no registry. This plan is the one mechanical rewrite and its guard, kept in one plan with the generator change and the `make check-docs` gate, as the phase instructions require.
Output: one new production file in helpers, two helper files changed, 23 module files changed mechanically, three tests, the generator, three docs pages, AGENTS.md.
</objective>
