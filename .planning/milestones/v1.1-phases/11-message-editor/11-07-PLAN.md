## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the bot can remember, on any replica, that it is waiting for one person's next private message for one part of one group's message, and the person can end that wait with `/cancel`.

<objective>
Build the Redis wait store and `/cancel` (D-03, D-04, D-12, D-13; research S-02 "/cancel", S-03 with the verified Lua scripts of "Code Examples"), registered through a new `LoadSettingsInput` that `LoadSettings` calls.

Purpose: the editor's Set button (plan 11-09) writes a wait and the typed-reply door (plan 11-11) claims it; both need one store whose atomic scripts make a double delivery, an album or a second replica act once.
Output: `settings_input.go`, its test file, one line in `settings.go`, AGENTS.md, the regenerated settings docs page.
</objective>
