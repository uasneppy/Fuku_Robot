## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the owner presses Set on a part in the private menu and the bot asks for the next message, until a time it states, with a Cancel button; Remove takes a part out at once; in a menu opened in the group those buttons point the owner to the private chat.

<objective>

Purpose: Set is what the typed-reply door (plan 11-11) answers; Remove and the parts rows finish what the page shows (EDIT-01).
Output: the actions file, the renderer's part rows and the registrations in `settings_edit.go`, tests, AGENTS.md.
</objective>
