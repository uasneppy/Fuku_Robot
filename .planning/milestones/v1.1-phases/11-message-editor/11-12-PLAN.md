## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the owner sees, in their private chat, exactly the message members will get: one part with Preview, the whole thing with Full preview, filled in with their own name and the group's title.

<objective>
Add Preview and Full preview to the three editor pages (D-01, D-10; EDIT-06; UI-SPEC "Preview and Full preview"; research S-07), sending through the group's own builder and send function to the presser's private chat only.

Purpose: Full preview is the owner's check of what the dry run cannot see (a stale file ID, how a GIF renders), and it must be byte-for-byte the group's message.
Output: the preview file and tests, the preview rows and registrations in `settings_edit.go`, the extended layout, byte and fit tests.
</objective>

## Planner assumptions (flagged)

- Row count: the UI-SPEC says "at most 8 rows" and its own group-menu mock has 9 (the Open in private row on top of a fully set page). The planner reads the rule as 8 in a private menu and 9 in a group menu, which is what the mocks show; Telegram has no lower row limit than its 100 buttons.

- UI-SPEC A15: Rules Full preview previews the rules message itself, not the click-to-read message of private rules.
- Plan 11-09's layout expectations in `TestSettingsEditPages`, `TestSettingsEditCallbackBytes` and `TestSettingsEditPagesFitEveryLocale` gain the preview rows here; no other existing test reads an editor page's rows.
