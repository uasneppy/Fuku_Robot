## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the length, button-link and media rules the commands apply, and the placeholder filling a join uses, are each one exported function that the commands already call, so the editor can apply exactly the same rules before it saves anything.

<objective>
Extract four behaviour-preserving helpers that the commands keep using and the editor will reuse (research S-01, S-04; D-06, D-07, D-08): `content.ExtractMedia`, `content.TextLengthRefusal`, `content.ValidButtonURL` and `formatting.FillPlaceholders`, plus the new `formatting.VisibleLength`.

Purpose: parity by construction. The editor's dry run (plan 11-10) must refuse what `/setwelcome` refuses and fill placeholders the way a real join does, without a Telegram call for `{count}` or a database read for `{rules}`.
Output: the two library files and two new test files.
</objective>
