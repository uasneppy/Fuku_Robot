## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the owner presses Set, sends the message in private, and it is saved exactly as the command would save it, with a clear page showing what changed, on whichever replica gets the message; a late reply is told the wait ended.
