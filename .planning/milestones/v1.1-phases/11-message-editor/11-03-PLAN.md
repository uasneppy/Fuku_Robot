## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the editor can read a group's welcome, goodbye and rules without creating anything and without hiding a failed read, and it can save one part of a message (only the text, only the media, only the buttons) without touching the others.

<objective>
Add the side-effect-free, error-returning reads and the column-targeted writes the editor needs (research S-05): `greetings.LoadSettingsContext`, `rules.LoadRulesContext`, and `Set{Welcome,Goodbye}{Text,Media,Buttons}Only`.

Purpose: `GetGreetingSettings` and `GetChatRulesInfo` create rows and swallow errors, so a page that used them would write on every Main draw and show "Default" after a failed read; `SetWelcomeText` writes all four columns, so it cannot save one part.
Output: the two repositories and two new test files. No migration, no model change, no new cache key.
</objective>
