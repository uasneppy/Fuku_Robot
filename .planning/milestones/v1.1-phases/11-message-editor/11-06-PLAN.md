## Phase Goal

**As a** group owner, **I want to** write the welcome, goodbye and rules from the bot's private chat by sending them as messages, **so that** I can set them up without typing commands in the group.

After this plan the settings pipeline can refuse a forged editor button before it reads anything, and it can require the "change group info" right that `/setwelcome` requires, judged the same way for a button press and, later, for a typed reply.

<objective>
Add two small, additive hooks to the shared settings pipeline (research S-06, S-08; D-02, D-05): `settingsPageAction.Validate`, called from `settingsCheckFields`, and the right `settingsRightChangeInfo` with the pure `settingsRightRefusalFor` that the press and the typed-reply door share.

Purpose: the editor's page actions carry a part code `t` that must be one of the page's parts before any I/O (UI-SPEC "Callback data"), and Welcome and Goodbye changes need the change-info right their commands need (UI-SPEC rights table). This edits `settings_pages.go` and `settings_menu.go` deliberately and minimally; D-02's "settings_pages.go is not edited" is about registering pages, which still happens from each page's own file.
Output: the two shared files and one new test file.
</objective>
