# 📦 Settings Commands

One control panel for the whole facility.

**Admin commands**:
- `/settings`: Open the settings menu. In the group it opens here or in private; in a private chat with me it lists the groups you can manage.
- `/timezone`: Show the group's timezone, or change it: /timezone Europe/Kyiv, /timezone +2 or /timezone default.

Pages: Staff Group, blocked sources, lockdown, captcha, antiflood, warnings, locks, blacklist, filters, welcome, goodbye, rules, notes, reactions, member requirements, deletion, switches, language, timezone, log channel, anonymous admins and access. Lists and messages are set by sending them to me in private. A change in the menu is the same as its command: /linkstaff, /unlinkstaff, /unlockdown, /autolockdown, /captcha, /captchamode, /captchatime, /captchaaction, /setflood, /setfloodmode, /delflood, /setwelcome, /setgoodbye, /setrules and the rest. Member requirements have no command: the menu is the only way to set them.

Only the owner can open the menu, unless the owner lets admins in. The commands still work for admins. A menu opened in the group answers only to whoever opened it. Every press checks that you are still allowed in and have the right its command needs.

This module can be accessed using the following aliases:
