# 📦 Settings Commands

Manage this group from one button menu.

**Admin commands**:
- `/settings`: Open the settings menu, here in the group or in private.

The menu covers the Staff Group link, lockdown (state, lift and the automatic triggers), captcha and antiflood. Every change made in it is the same as the matching command: /linkstaff, /unlinkstaff, /unlockdown, /autolockdown, /captcha, /captchamode, /captchatime, /captchaaction, /setflood, /setfloodmode and /delflood.

A menu opened in the group answers only to the admin who opened it. Every press checks that you are still an admin of the group, and each change needs the same right as its command.


## Module Aliases

This module can be accessed using the following aliases:

- `settings`
