# 📦 Chat Commands

**🗨 Conversations**

In a group whose owner turned conversations on, I answer members who talk to me. Briefly. I have no powers in conversation: a chat line from me bans, mutes or changes nothing.

**Commands for everyone**
- /ask `<text>` — asks me something. /xeno works too.

**Notes**
I answer a message that mentions me, a reply to one of my conversation replies, and /ask. I start no conversation, and I never talk in a private chat. Only the group's owner can turn conversations on, in /settings in a private chat with me.
What goes to the AI provider the owner chose: the message, the message it replies to, the group's recent conversation with me, members' first names, the group's title and language, and the date. No IDs and no usernames.

**Example**
`/ask what is tempe?`
